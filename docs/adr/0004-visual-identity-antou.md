# ADR-0004 视觉识别「案头」

- 状态：已采纳（2026-10-15），项目所有者从三个方向中选定

## 决定
暖白纸面、墨色文字、朱砂点睛。用户确认 = 盖朱印「定」；AI 建议 = 铅笔批注（虚线、灰墨）。AI 成员头像是矿物颜料的白文印章。完整规范见 `docs/DESIGN.md`。

## 被否决的方向
- 几何工坊（包豪斯原色色块）：个性强，但与"区分建议和确认"没有内在联系。
- 夜间控制室（深色等宽）：在开发者工具里太常见，辨识度最低。

## 理由
产品最独特的能力（区分 AI 建议与用户确认、标明来源）直接成为视觉语言，而不是贴在界面上的装饰。

## 保护
`frontend/src/design/*`、`docs/DESIGN.md`、印章与盖章相关样式属于品牌视觉基线；修改前请先与维护者确认并重新检查六种纸的对比度。
