# ADR-0001 只有用户能触发 AI 回复

- 状态：已采纳（2026-10-15）
- 决策人：项目所有者

## 背景
群里有多个 AI。是否允许 AI 主动 @ 其他 AI，决定了系统是"用户主导的群聊"还是"自治的多 Agent 系统"。

## 决定
只有用户的 @ 会触发回复。AI 只回应用户本轮的请求；AI 在回复中写 @ 不会触发任何人。没有 @ 任何成员的用户消息只记录，不触发回复。

## 后果
- 不需要链式触发上限、防死循环、主持人模型。
- 每条成员消息都有明确的 `ReplyToID`（指向触发它的用户消息）和 `TurnID`。
- 提示词里明确告诉成员"@ 其他成员不会让他们回复，需要谁参与请建议用户 @ 他"。
- 若未来要放开，数据模型已具备触发关系字段，需要新的 ADR。
