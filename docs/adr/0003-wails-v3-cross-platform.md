# ADR-0003 Wails v3 桌面应用，三平台

- 状态：已采纳（2026-10-15）

## 决定
- 形态：Wails v3 桌面应用（Go 后端 + 系统 WebView 前端），无边框窗口、自绘标题栏。
- 平台：Windows 10/11、macOS、Linux 同等对待。
- 版本：Wails v3（2026-10 时为 beta，核心 API 已标稳定）。半透明材质等平台特有功能可能变动，只作为加分项使用。

## 理由
- 界面"风格独特、耐看"的要求下，浏览器标签页的外框会稀释风格；桌面窗口可以完全掌控外观、快捷键、通知。
- Go 后端符合项目所有者的技术方向。
- 业务核心（`internal/*`）不依赖 Wails，以后加 Web 版只需替换外壳。

## 约束（来自三平台）
- 设计以 Windows 10 和 Linux 的能力为基准：没有毛玻璃，风格靠纯色、字体、版式、动效成立。
- 字体随应用打包；滚动条、焦点、表单控件全部自绘。
- 三种 WebView 内核（Chromium / WebKit / WebKitGTK）都要验收。
