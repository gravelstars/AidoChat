# ADR-0002 同时 @ 多位成员时：依次或同时，可切换

- 状态：已采纳（2026-10-15）

## 决定
- 每个群有默认回复方式 `DefaultMode`，新群默认"依次"（serial）。
- 发送框旁有切换开关，只对当前这条消息生效，发送后恢复群默认。
- 依次：按 @ 出现顺序；@所有人 时按群成员顺序。后者能看到前者本轮的回复。
- 同时：所有人并发作答，看到的上下文都截止到用户这条消息，互相看不到本轮的回答。
- 依次模式下某位成员失败：标为 error 可重试，后续成员继续，且看不到失败的回复。
- 停止：取消整个轮次，已生成部分保留。
- 轮次模式记录在用户消息的 ReplyMode 字段，供重试时重建当时的上下文可见性。

## 理由
"持续讨论"要求成员能补充、审查彼此的观点；在 AI 不能互相 @ 的前提下（ADR-0001），依次回复是单轮内形成讨论的唯一方式。同时回复适合"各自给方案、我来比较"。
