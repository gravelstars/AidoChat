# ADR-0008 DIY 的边界：改身份与内容，不改结构与含义

- 状态：已采纳（2026-10-15），项目所有者确认

## 原则
「案头」里每种颜色和笔迹都有含义（朱 = 用户，虚线 = AI 建议，印 = 定论）。DIY 只开放"属于用户自己的东西"，不开放承载含义的部分。

## 开放
1. **成员头像**：印章（一字 + 六种颜料）或图片（PNG / JPG / GIF / WebP）。**动图不做任何限制，始终播放**——选择动图的人默认接受它的热闹。
2. **头像作用范围：默认 + 群内覆盖**。成员有默认头像；每个群可以单独覆盖（`Group.MemberAvatars`，落在 `group_members` 的三个可空列）。头像只影响界面，不进入提示词。
3. **纸张**：六种精选纸，每种是一整套校准过的 token——白昼：宣纸（默认）、素笺、麻纸、青笺；夜间：夜读、乌金。白昼和夜间各选一张，可跟随系统切换。
4. **私印**：用户刻 1–4 字的印，白文或朱文。它是用户在群里的头像，也是确认纪要时盖的印；没刻过（保持默认"我"+白文）时，确认印仍为「定」。
5. **阅读偏好**：正文字号（小 14 / 中 15 / 大 17）、排版密度（舒适 / 紧凑）。

## 不开放
- 自定义壁纸 / 背景图：对比度无法保证，会压平纸面层次，图片颜色会干扰朱色的含义。
- 自定义纸色（取色器、冷暖滑杆）与自定义纸纹：自由度换来的满足感有限，却要承担"某些组合不好看"的风险。
- 朱色、三种笔迹、字体、圆角、组件样式。
- 群标识（群印）：暂缓，以后再议。

## 后果
- 新增纸张必须完整定义 tokens.css 中一整块变量并通过对比度检查，由项目所有者完成。
- 所有显示成员头像的地方必须通过 `avatarOf(member, group)`（前端）/ `domain.AvatarOf`（Go）取值。
