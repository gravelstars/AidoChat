# 产品范围

## 一句话

本地运行的 AI 群聊：把不同的 AI 像数字员工一样拉进同一个群，用 @ 点名交流；每个群有自己的记录和纪要，AI 进哪个群就只知道哪个群的事。

## 路线：精简

不做大而全。每加一个功能都要回答：“它让‘群 + @ + 纪要’这个核心更好用了吗？”答不上来就不做。

## 当前版本做什么

1. **成员**：完整显示名、独立短印文、印章或图片头像、一句话简介、角色提示词、模型服务与模型。
2. **模型服务**：OpenAI 兼容（覆盖国内大多数厂商、Ollama、OpenAI）与 Anthropic 两类；Key 存系统钥匙串。
3. **群聊**：新建群（名称、主题、成员、默认回复方式），邀请/移出成员、排序、改名、归档、删除。
4. **@ 交流**：@单人、@多人、@所有人；多人时可选依次或同时回复；没有 @ 的消息只记录不回复；停止、原地重试。
5. **群纪要**：自动整理背景、方案、决定、待办；标明真实来源；AI 建议与用户确认分开；用户盖章、否决、改写。
6. **聊天附件**：PNG/JPEG/WebP、TXT/Markdown、文本型 PDF、Word/PowerPoint/Excel、CSV/JSON、代码和日志；本地保存和预览；只有被点名且开启图片能力的成员会收到图片。
7. **分享图片**：选择起止消息导出为 1080 宽分页 PNG；支持当前纸/宣纸、群名/时间/署名开关和原生目录保存。
8. **本地持久化**：SQLite 数据库、附件文件和群记忆；重启后继续讨论。
9. **外观**：宣纸、素笺、麻纸、青笺、夜读、乌金六种纸；日夜/跟随系统、阅读字号与密度。

## 明确不做

| 不做 | 原因 |
|---|---|
| AI 主动 @ 其他 AI、AI 之间自动对话 | ADR-0001：只有用户能触发回复，行为可控 |
| AI 的个人记忆、跨群记忆 | 记忆以群为单位，这是产品定义 |
| 工具调用、联网搜索、执行代码 | 会把产品拖向“Agent 平台”，偏离核心 |
| 扫描版 PDF OCR、视频附件 | 首期附件范围之外，后续再评估 |
| 多用户、账号、云同步 | 本地单用户应用 |
| 插件系统、提示词市场 | 大而全路线 |
| 语音 | 同上 |

## 隐私说明（界面中必须如实告知）

- 数据保存在本机。
- 调用云端模型时，被 @ 成员的上下文（群规则、群纪要、近期聊天记录和所需附件内容）会发送给该成员配置的模型服务。
- 整理纪要时，新的讨论会发送给“整理模型”所在的服务；整理只读取有来源的附件文字，不发送原图。
