# TASK-018 删除成员后仍不能下线模型服务

- 认领：Codex · 2026-10-17
- 来源：所有者实际使用反馈第1项；第2/4项仅讨论，不在本任务改动。
- 依赖：TASK-017已交付。

## 根因与方案

成员软删除保留历史身份，但MembersUsingProvider包含软删除成员；即使只过滤活跃成员，members.provider_id外键仍阻止物理删除。

将服务下线记为内部软删除：活跃成员仍阻止下线，已删除成员只保留历史外键；下线服务不再出现在配置、查询或新建成员中，清除系统凭证与纪要配置，保持现有失败回滚。数据库迁移新增内部deleted_at与活跃引用约束，不修改领域/前后端契约、历史消息或受保护文件。保留服务的非凭证元数据用于历史关联，不提供恢复入口。

## 验收

- [x] 活跃成员仍阻止下线，提示只包含活跃成员。
- [x] 删除最后使用成员后能下线；历史姓名/头像/消息仍在。

- [x] 下线服务不可被旧表单重新保存、重新引用；重启后仍隐藏。
